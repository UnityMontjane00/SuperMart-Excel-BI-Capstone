# SuperMart Excel Business Intelligence Capstone

## Project Overview

The SuperMart Excel Business Intelligence Capstone is an advanced Excel analytics project based on a supermarket business scenario.

The project uses Excel to **prepare, clean, analyse and visualise business data** and turn it into insights that can support management decision-making.

## Business Objectives

The analysis focuses on:

* Sales and profit performance
* Customer value
* Product and category performance
* Regional performance
* Delivery performance
* Returns and operational efficiency

## What I Did

* Consolidated quarterly sales data
* Cleaned and standardised customer data
* Identified duplicate records
* Used lookup and advanced Excel functions
* Created calculated fields for revenue and profit
* Classified customers by value
* Analysed data using PivotTables
* Applied Conditional Formatting and Data Validation
* Created interactive slicers and timelines
* Built a Business Intelligence dashboard
* Translated analysis into business insights

## Excel Skills Demonstrated

**Data Preparation:** Cleaning, consolidation, transformation

**Functions:** PROPER, XLOOKUP, INDEX-MATCH, IF/IFS, UNIQUE, COUNTIF, AVERAGEIF, TEXTJOIN

**Analysis:** PivotTables, calculated fields, customer classification, regional and product analysis

**Visualisation:** Charts, KPIs, slicers, timelines and interactive dashboards
